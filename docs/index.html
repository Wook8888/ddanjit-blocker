개인정보처리방침

최종 수정일 · 시행일: 2026년 9월 21일

딴짓 차단기는 어떤 개인정보도 수집하지 않습니다. 개발자가 운영하는 서버가 없고, 개발자에게 전송되는 데이터도 없습니다. 사용자가 정한 설정은 사용자의 브라우저 안에, 크롬 동기화를 켰다면 사용자 본인의 구글 계정 안에만 보관됩니다.

1. 수집하지 않는 정보

이 확장 프로그램은 아래 정보를 하나도 수집·저장·전송하지 않습니다.

  • 이름, 이메일, 계정 정보 등 개인 식별 정보를 수집하지 않습니다.
  • 방문 기록, 검색 기록, 열람한 페이지의 내용을 수집하지 않습니다.
  • IP 주소, 위치 정보, 하드웨어 기기 식별자(광고 ID·MAC 주소 등)를 수집하지 않습니다.
  • 사용 통계, 분석 데이터, 오류 보고를 수집하지 않습니다.
  • 쿠키, 로그인 정보, 비밀번호, 입력한 양식의 내용을 수집하지 않습니다.

분석 도구나 광고 SDK를 일절 포함하지 않으며, 외부 서버와 통신하는 코드가 존재하지 않습니다.

2. 요청하는 권한과 사용 목적

권한사용 목적
storage 아래 7항의 설정을 브라우저에 보관하고, 크롬 동기화를 켠 경우 사용자의 다른 크롬과 맞추기 위해 사용합니다.
declarativeNetRequestWithHostAccess 차단 규칙을 크롬에 등록하기 위해 사용합니다. 이 방식은 규칙만 크롬에 넘겨줄 뿐, 확장 프로그램이 실제 요청 내용을 들여다보지 않습니다.
사이트 접근 권한
(선택적)		 사용자가 차단 목록에 직접 추가한 사이트에 대해서만 그때그때 요청합니다. 설치 시점에 모든 사이트에 대한 권한을 요구하지 않으며, 이 권한은 해당 사이트로의 이동을 차단 화면으로 돌리는 데에만 쓰입니다.

3. 제3자 제공 및 외부 전송

개발자가 수집하는 정보가 없으므로 제3자에게 제공하거나 판매하는 정보도 없습니다. 이 확장 프로그램은 어떤 외부 서버와도 통신하지 않습니다. 크롬 동기화를 켠 경우의 기기 간 전달은 사용자 본인의 구글 계정 안에서만 이루어집니다.

4. 데이터 삭제

chrome://extensions 에서 이 확장 프로그램을 삭제하면 그 브라우저에 보관된 설정이 함께 지워집니다. 크롬 동기화로 구글 계정에 보관된 사본은 모든 기기에서 확장 프로그램을 삭제하거나, 크롬 동기화 데이터 관리 페이지에서 동기화를 초기화해 지울 수 있습니다. 개발자는 이 데이터를 갖고 있지 않으므로 별도의 삭제 요청 절차가 필요 없습니다.

5. 아동의 개인정보

이 확장 프로그램은 연령과 무관하게 어떤 개인정보도 수집하지 않습니다.

6. 방침 변경

내용이 변경되면 이 페이지를 갱신하고 상단의 시행일을 함께 수정합니다. 수집하는 정보가 생기는 등 중대한 변경이 있을 경우 확장 프로그램 업데이트 안내를 통해 별도로 알립니다.

7. 브라우저에만 보관되는 설정 수집 아님

확장 프로그램이 동작하려고 사용자의 브라우저에 아래 설정만 보관합니다. 개발자에게 전송되지 않습니다.

  • 차단 목록 · 예외 목록 (이전 목록 보관함 포함)
  • 잠금 문제 단어 리스트
  • 기기 이름(과 구분용 임의 번호), 기능 설정(켜짐/꺼짐, 풀어야 할 문제 수, 틀렸을 때 기다리는 시간)

크롬 동기화와 이 기기 동기화를 켜 두면, 차단·예외 목록(이전 목록 보관함 포함)과 기기 이름은 사용자 본인의 구글 계정을 통해 본인의 다른 크롬으로만 전달됩니다. 잠금 문제 단어 리스트는 기기마다 따로 보관되며, 사용자가 직접 대표로 올리기를 누른 단어 리스트 하나만 같은 방식으로 본인의 다른 크롬에서 내려받을 수 있습니다. 그 밖의 설정은 기기마다 따로 보관됩니다. 엑셀로 내보내기를 누르면 같은 내용이 사용자의 컴퓨터에 파일로 저장됩니다.

In short

Ddanjit Blocker collects no personal data whatsoever. There is no developer server and nothing is sent to the developer. Your settings stay in your own browser — and, if you turn on Chrome Sync, in your own Google account.

1. Information we do not collect

This extension does not collect, store, or transmit any of the following:

  • Names, email addresses, or account details — not collected.
  • Browsing history, search history, or the content of pages you view — not collected.
  • IP addresses, location, or hardware device identifiers (advertising ID, MAC address, etc.) — not collected.
  • Usage analytics, telemetry, or crash reports — not collected.
  • Cookies, credentials, passwords, or form input — not collected.

The extension contains no analytics or advertising SDKs, and no code that communicates with any external server.

2. Permissions and why they are needed

PermissionPurpose
storage To keep the settings in section 7 in your browser and, if Chrome Sync is on, keep them in step with your other Chrome browsers.
declarativeNetRequestWithHostAccess To register blocking rules with Chrome. With this API the extension hands Chrome a set of rules; it never inspects the requests themselves.
Host access
(optional)		 Requested only for sites you add to your block list, at the moment you add them. The extension does not request access to all sites at install time, and this access is used solely to redirect navigation to the block page.

3. Third parties

Since the developer collects no data, none is shared or sold. The extension does not communicate with any external server. Transfer between devices, if you turn on Chrome Sync, happens only within your own Google account.

4. Deleting your data

Removing the extension from chrome://extensions deletes the settings kept in that browser. The copy kept in your Google account by Chrome Sync is removed when you remove the extension from all your devices, or by resetting sync on the Chrome Sync data page. The developer holds none of this data, so no deletion request is needed.

5. Children's privacy

This extension collects no personal data from users of any age.

6. Changes to this policy

If this policy changes, this page and the effective date above will be updated. Material changes — such as beginning to collect any data — will additionally be announced through the extension's update notes.

7. Settings kept only in your browser not collected

To work, the extension keeps only these settings in your browser. They are never sent to the developer.

  • Block list · exception list (including the archive of earlier lists)
  • Unlock word list
  • Device name (and a random tag to tell your devices apart), feature settings (on/off states, number of questions, wait time after a wrong answer)

If Chrome Sync and Sync this device are on, the block and exception lists (including the archive of earlier lists) and the device name travel only to your own other Chrome browsers through your own Google account. Unlock word lists are kept separately on each device; only a single word list that you choose to upload as the shared list can be downloaded on your other Chrome browsers the same way. All other settings stay on each device. Clicking Export to Excel saves the same content as a file on your computer.
