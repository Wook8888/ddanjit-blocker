딴짓 차단기는 어떤 개인정보도 수집하지 않습니다. 개발자가 운영하는 서버가 없고, 개발자에게 전송되는 데이터도 없습니다. 사용자가 정한 설정은 사용자의 브라우저 안에, 크롬 동기화를 켰다면 사용자 본인의 구글 계정 안에만 보관됩니다.

1. 수집하지 않는 정보

이 확장 프로그램은 아래 정보를 하나도 수집·저장·전송하지 않습니다.

  • 이름, 이메일, 계정 정보 등 개인 식별 정보를 수집하지 않습니다.
  • 방문 기록, 검색 기록, 열람한 페이지의 내용을 수집하지 않습니다.
  • IP 주소, 위치 정보, 하드웨어 기기 식별자(광고 ID·MAC 주소 등)를 수집하지 않습니다.
  • 사용 통계, 분석 데이터, 오류 보고를 수집하지 않습니다.
  • 쿠키, 로그인 정보, 비밀번호, 입력한 양식의 내용을 수집하지 않습니다.

분석 도구나 광고 SDK를 일절 포함하지 않으며, 외부 서버와 통신하는 코드가 존재하지 않습니다.

2. 사용자의 브라우저에만 보관되는 설정 수집 아님

아래 항목은 개발자가 수집하는 정보가 아닙니다. 확장 프로그램이 동작하려고 사용자의 브라우저 안(크롬의 chrome.storage)에 보관하는 설정이며, 개발자에게 전송되지 않습니다.

보관 항목내용다른 기기와 동기화
차단 목록 · 예외 목록사용자가 직접 입력한 도메인예
차단 화면 문구차단 화면에 표시할 기호와 짧은 문구예
잠금 문제 단어잠금을 풀 때 나오는 단어·발음·뜻 (사용자가 바꿀 수 있음)예
동기화 기록최근 10회의 차단·예외 목록, 바뀐 시각, 바꾼 기기의 이름예
기기 이름 · 기기 구분 번호사용자가 붙인 기기 이름("회사 PC" 등)과, 내 기기끼리 구분하려고 확장 프로그램이 임의로 만든 짧은 번호. 하드웨어 정보와는 무관합니다.기록 안에서만

이 확장 프로그램은 비밀번호를 사용하지 않습니다. 잠금은 단어 문제로만 이루어지며, 계정·이메일·비밀번호를 묻거나 저장하지 않습니다.

크롬 동기화에 대하여

사용자가 크롬 동기화를 켜 두었다면, 위 표에서 "예"로 표시된 항목이 chrome.storage.sync 를 통해 사용자 본인의 구글 계정에 보관되어 같은 계정으로 로그인한 사용자 본인의 다른 크롬으로만 전달됩니다. 이 전달은 구글이 제공하는 크롬 동기화 기능이 처리하며, 개발자는 이 데이터에 접근할 수 없고 중간에 어떤 서버도 두지 않습니다. 크롬 설정에서 동기화를 끄면 데이터는 그 기기 안에만 남습니다. (구글의 처리 방식은 구글 개인정보처리방침을 따릅니다.)

엑셀 백업 파일에 대하여

사용자가 직접 엑셀로 내보내기를 누른 경우에만, 차단·예외 목록, 차단 화면 문구, 잠금 문제 단어가 담긴 파일이 사용자의 컴퓨터에 저장됩니다. 이 파일은 어디로도 전송되지 않으며, 보관과 삭제는 사용자가 정합니다.

3. 요청하는 권한과 사용 목적

권한사용 목적
storage 위 2항의 설정을 브라우저에 보관하고, 크롬 동기화를 켠 경우 사용자의 다른 크롬과 맞추기 위해 사용합니다.
declarativeNetRequestWithHostAccess 차단 규칙을 크롬에 등록하기 위해 사용합니다. 이 방식은 규칙만 크롬에 넘겨줄 뿐, 확장 프로그램이 실제 요청 내용을 들여다보지 않습니다.
사이트 접근 권한
(선택적)		 사용자가 차단 목록에 직접 추가한 사이트에 대해서만 그때그때 요청합니다. 설치 시점에 모든 사이트에 대한 권한을 요구하지 않으며, 이 권한은 해당 사이트로의 이동을 차단 화면으로 돌리는 데에만 쓰입니다.

4. 제3자 제공 및 외부 전송

개발자가 수집하는 정보가 없으므로 제3자에게 제공하거나 판매하는 정보도 없습니다. 이 확장 프로그램은 어떤 외부 서버와도 통신하지 않습니다. 크롬 동기화를 켠 경우의 기기 간 전달은 사용자 본인의 구글 계정 안에서만 이루어집니다.

5. 데이터 삭제

chrome://extensions 에서 이 확장 프로그램을 삭제하면 그 브라우저에 보관된 설정이 함께 지워집니다. 크롬 동기화로 구글 계정에 보관된 사본은 모든 기기에서 확장 프로그램을 삭제하거나, 크롬 동기화 데이터 관리 페이지에서 동기화를 초기화해 지울 수 있습니다. 개발자는 이 데이터를 갖고 있지 않으므로 별도의 삭제 요청 절차가 필요 없습니다.

6. 아동의 개인정보

이 확장 프로그램은 연령과 무관하게 어떤 개인정보도 수집하지 않습니다.

7. 방침 변경

내용이 변경되면 이 페이지를 갱신하고 상단의 시행일을 함께 수정합니다. 수집하는 정보가 생기는 등 중대한 변경이 있을 경우 확장 프로그램 업데이트 안내를 통해 별도로 알립니다.

In short

Ddanjit Blocker collects no personal data whatsoever. There is no developer server and nothing is sent to the developer. Your settings stay in your own browser — and, if you turn on Chrome Sync, in your own Google account.

1. Information we do not collect

This extension does not collect, store, or transmit any of the following:

  • Names, email addresses, or account details — not collected.
  • Browsing history, search history, or the content of pages you view — not collected.
  • IP addresses, location, or hardware device identifiers (advertising ID, MAC address, etc.) — not collected.
  • Usage analytics, telemetry, or crash reports — not collected.
  • Cookies, credentials, passwords, or form input — not collected.

The extension contains no analytics or advertising SDKs, and no code that communicates with any external server.

2. Settings kept only in your browser not collected

The items below are not information collected by the developer. They are settings the extension keeps inside your browser (Chrome's chrome.storage) so that it can work, and they are never sent to the developer.

ItemDescriptionSynced to your other devices
Block list · exception listDomains you entered yourselfYes
Block page textThe symbol and short message shown on the block pageYes
Unlock wordsWords, pronunciations and meanings used by the unlock question (editable by you)Yes
Sync historyThe last 10 versions of your lists, when they changed, and the name of the device that changed themYes
Device name · device tagThe name you give a device ("Work PC") and a short random tag the extension creates to tell your own devices apart. It has nothing to do with hardware.Only inside the history
Blocking on · lock onWhether each feature is turned onNo (per device)
Unlock timeKeeps settings open for 5 minutes after a correct answer. Cleared when the browser closes.No

This extension does not use passwords. The lock is a word question only. It never asks for or stores an account, email address or password.

About Chrome Sync

If you have Chrome Sync enabled, the items marked "Yes" above are kept via chrome.storage.sync in your own Google account and delivered only to your own other Chrome browsers signed in to that account. This is handled by Google's Chrome Sync feature; the developer cannot access this data and operates no server in between. Turning Chrome Sync off keeps the data on that device only. (Google's handling is governed by the Google Privacy Policy.)

About the Excel backup file

Only when you click Export to Excel, a file containing your lists, block page text and unlock words is saved on your computer. It is never sent anywhere; you decide whether to keep or delete it.

3. Permissions and why they are needed

PermissionPurpose
storage To keep the settings in section 2 in your browser and, if Chrome Sync is on, keep them in step with your other Chrome browsers.
declarativeNetRequestWithHostAccess To register blocking rules with Chrome. With this API the extension hands Chrome a set of rules; it never inspects the requests themselves.
Host access
(optional)		 Requested only for sites you add to your block list, at the moment you add them. The extension does not request access to all sites at install time, and this access is used solely to redirect navigation to the block page.

4. Third parties

Since the developer collects no data, none is shared or sold. The extension does not communicate with any external server. Transfer between devices, if you turn on Chrome Sync, happens only within your own Google account.

5. Deleting your data

Removing the extension from chrome://extensions deletes the settings kept in that browser. The copy kept in your Google account by Chrome Sync is removed when you remove the extension from all your devices, or by resetting sync on the Chrome Sync data page. The developer holds none of this data, so no deletion request is needed.

6. Children's privacy

This extension collects no personal data from users of any age.

7. Changes to this policy

If this policy changes, this page and the effective date above will be updated. Material changes — such as beginning to collect any data — will additionally be announced through the extension's update notes.
