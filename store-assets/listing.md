# 크롬 웹스토어 리스팅 문구

> 대시보드 → **Store listing** 에 그대로 복사해서 넣으면 됩니다.

---

## 1. 확장 프로그램 이름 — 확정

```
딴짓 차단기
```

만드신 계기("나도 모르게 들어가서")와 정확히 맞고, 한 번 보면 기억에 남습니다.
스토어에 같은 이름이 없어 브랜드로 키울 수 있습니다. (6자 / 제한 75자)

`manifest.json` 의 `name` 과 팝업·차단 페이지 문구도 모두 이 이름으로 교체했습니다.

> 검토했던 다른 후보: `딴짓 차단기 — 유튜브·커뮤니티 사이트 차단` (검색 노출은 유리하나
> 목록에서 뒤가 잘림), `사이트 차단기` (검색어와 일치하나 동명 확장이 많아 묻힘).
> 키워드를 길게 나열한 이름은 정책상 스팸으로 걸릴 수 있으니 주의하세요.

---

## 2. 요약 (Summary) — 확정 · 57자 / 제한 132자

```
차단할 사이트를 적기만 하면 됩니다. 서브도메인까지 한 번에 차단하고, 필요한 곳만 예외로 열어두세요.
```

`manifest.json` 의 `description` 에도 같은 문장을 넣었습니다.
매니페스트 description 과 스토어 요약은 같게 두는 편이 관리가 편합니다.

---

## 3. 상세 설명 (Detailed description)

```
유튜브와 커뮤니티 사이트를 나도 모르게 들어가고 있었습니다.
더 나은 나를 만들기 위한 첫걸음으로 이 앱을 만들었습니다.

■ 회사 PC와 집 노트북, 차단 목록이 동기화됩니다

같은 구글 계정으로 로그인한 크롬끼리 차단 목록이 자동으로 맞춰집니다.
한 곳에서 고치면 다른 기기에도 곧바로 반영됩니다. 서버도, 가입도 필요 없습니다.

■ 차단할 사이트를 적기만 하면 됩니다

naver.com 처럼 주소 하나만 넣으면 m.naver.com, blog.naver.com 같은
서브도메인까지 함께 차단됩니다. 목록에 추가하는 즉시 적용됩니다.

■ 필요한 곳만 예외로 열어두세요

네이버는 막고 싶지만 지도는 써야 할 때가 있습니다.
예외 목록에 map.naver.com 을 넣으면 그곳만 열립니다.
예외는 차단보다 항상 우선합니다.

■ 충동적으로 풀지 못하게

설정 변경을 잠글 수 있습니다.
잠금을 풀기 위한 간단한 단어 맞추기 게임을 하면 됩니다.
문제에 나올 단어는 엑셀에서 직접 골라 넣을 수 있습니다.

■ 군더더기 없는 차단 화면

"잠깐!" 한마디로 멈춰 세웁니다.
설정할 것도, 꾸밀 것도 없습니다.

■ 어떤 주소가 막혔는지 바로 보여드립니다

차단 화면에 막힌 주소 전체가 표시됩니다.
어느 차단 규칙에 걸렸는지도 함께 알려드립니다.


● 어떻게 동작하나요

크롬의 declarativeNetRequest 를 사용해 페이지 요청 단계에서 끊어냅니다.
사이트가 열리기 시작하기 전에 차단되므로 화면에 잠깐 스치는 일도 없습니다.


● 개인정보

이 확장 프로그램은 개발자에게 어떤 데이터도 보내지 않습니다.
외부 서버와 통신하지 않으며, 방문 기록을 읽거나 저장하지 않습니다.
차단 목록과 설정은 사용자의 브라우저에 저장되고, 크롬 동기화를 켜 두었다면
사용자 본인의 구글 계정을 통해 본인의 다른 크롬으로만 전달됩니다.
계정·이메일·비밀번호를 묻거나 저장하지 않습니다.

권한도 필요한 만큼만 요청합니다. 설치할 때 모든 사이트에 대한 권한을
요구하지 않고, 사용자가 차단 목록에 추가한 사이트에 대해서만
그때그때 권한을 요청합니다.


● 알아두실 점

크롬 확장 프로그램 관리 화면에서 이 확장을 끄거나 삭제하면 차단도 해제됩니다.
이 도구는 무심코 하는 딴짓을 막아주는 용도이지, 작정하고 뚫으려는 시도까지
막아주지는 못합니다.
```

## 4. 카테고리

**Productivity → Workflow & Planning** 을 추천합니다.

같은 종류의 차단 도구들이 대부분 여기에 있고, 사용자들도 이 분류에서 찾습니다.
`Lifestyle → Well-being` 도 어울리지만 방문자 수가 적습니다.

> 카테고리 목록은 대시보드 드롭다운에서 최종 확인하세요. 스토어가
> 2023년 8월에 분류 체계를 3개 그룹으로 개편해서 문서와 실제가 다를 수 있습니다.

## 5. 언어

**한국어(Korean)** 로 설정합니다.

영어 리스팅은 지금 넣지 마세요. 영어권에는 BlockSite, StayFocusd 같은 강자가
이미 자리를 잡고 있어서, 번역만 얹어서는 묻힙니다.
한국어 시장에서 자리를 잡은 뒤에 붙이는 편이 낫습니다.
