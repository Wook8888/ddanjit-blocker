# 딴짓 차단기 (Chrome Extension)

지정한 사이트의 접속을 차단하는 크롬 확장 프로그램입니다.

## 설치 방법

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 `extension` 폴더를 선택
5. 툴바 퍼즐 아이콘 → 딴짓 차단기를 **고정(핀)** 해두면 편합니다

## 사용법

### 차단 목록

- `naver.com` 처럼 도메인을 입력하고 **차단** → 즉시 적용됩니다
- `www.` 와 서브도메인(`m.`, `blog.` 등)은 자동으로 함께 차단됩니다
- 목록의 `✕` 로 해제, 오른쪽 위 스위치로 전체 차단 일시 중지

### 예외 목록

차단된 도메인 안에서 **이 주소만 허용**하고 싶을 때 사용합니다.

| 차단 목록 | 예외 목록 | 결과 |
|---|---|---|
| `naver.com` | `map.naver.com` | 네이버는 막히고 지도는 열림 |

- 예외는 차단보다 항상 우선합니다
- 예외도 서브도메인을 포함합니다 (`map.naver.com` 허용 시 `pcmap.map.naver.com` 도 허용, `pcmap.naver.com` 은 아님)
- 상위 차단 도메인이 없는 예외를 넣으면 "지금은 효과가 없습니다" 라고 알려줍니다

### 설정

- **잠금** 켜기/끄기 — 기기마다 따로입니다
- **기기 이름** — 동기화 기록에 표시됩니다. 처음엔 운영체제 기준으로 자동으로 붙고, 언제든 고칠 수 있습니다

### 잠금 — 단어 문제

**비밀번호가 없습니다.** 잠금을 켜면 팝업을 열 때 단어 **한 문제**가 나옵니다.

- 단어 · **발음기호(IPA)** · 한국어 발음을 보고 뜻을 고르는 **4지선다**
- 맞히면 **5분 동안** 열립니다. 틀리면 곧바로 다른 단어로 새 문제가 나옵니다
- 잠금을 끄는 것도 잠금 안에 있으므로, 끄려면 문제를 풀어야 합니다
- 잠금 켜짐/꺼짐은 **기기마다 따로**입니다 (회사 PC 만 잠그는 식)

문제로 나올 단어는 **백업 · 불러오기**의 엑셀 `단어` 시트에서 직접 고칩니다.

| 단어 | 언어 | 발음기호 | 한국어 발음 | 뜻 |
|---|---|---|---|---|
| 木漏れ日 (komorebi) | 일본어 | /ko.mo.ɾe.bi/ | 코모레비 | 나뭇잎 사이로 부서져 내리는 햇살 |

- **단어**와 **뜻**만 필수입니다. 나머지 칸은 비워도 됩니다
- 보기 네 개는 적지 않습니다 — 정답은 그 줄의 뜻이고 나머지 셋은 다른 줄의 뜻에서 가져옵니다
- 그래서 단어가 **최소 4개**는 있어야 하며, 뜻이 겹치는 줄은 뒤엣것이 버려집니다
- 쓸 수 있는 줄이 4개 미만이면 불러오기를 막고, 기본 단어 10개로 돌아갑니다
- 단어 목록은 **동기화됩니다**

> 확장 프로그램 파일은 누구나 열어볼 수 있으니 정답도 함께 들어 있습니다.
> 목적은 완벽한 잠금이 아니라 **충동적인 해제를 한 박자 늦추는 것**입니다.

### 기기 간 동기화

같은 구글 계정으로 로그인해 크롬 동기화를 켜 두면 **차단 목록 · 예외 목록 · 차단 화면 문구 · 잠금 문제 단어**가 다른 기기에도 자동으로 맞춰집니다.
차단 켜기/끄기 스위치, 잠금, 기기 이름, 사이트 접근 권한은 기기마다 따로입니다.
다른 기기에서 넘어온 사이트가 있으면 툴바 아이콘에 노란 **!** 가 뜨니, 팝업에서 **권한 한 번에 허용**을 누르세요.
압축해제로 설치했다면 두 기기의 확장 ID를 맞춰야 합니다 → `SYNC-SETUP.md`

### 동기화 기록 · 되돌리기

목록이 바뀔 때마다 **그 시점의 목록 전체**를 최근 **10개**까지 남깁니다.
팝업 맨 아래 **"🔄 맥북에서 변경 · 3분 전"** 을 누르면 기록이 열립니다.

- 한 줄 = 시각 · 기기 이름 · 차단/예외 개수. 줄을 누르면 그때 도메인이 전부 펼쳐집니다
- 과거 줄의 **이 상태로 되돌리기** → 그 상태로 통째로 복원합니다 (확인을 위해 두 번 눌러야 합니다)
- 되돌린 결과는 **같은 계정의 모든 기기에 퍼집니다.** 되돌린 것도 기록에 남아 다시 되돌릴 수 있습니다
- 같은 기기가 5분 안에 연달아 고친 것은 **한 칸으로 묶입니다**
- 차단 목록이 아주 길면(한 칸 8KB 초과) 기록을 남기지 못하고, 그럴 때는 기록 화면에서 알려줍니다

### 백업 · 불러오기

팝업 아래 **백업 · 불러오기** 버튼 → 새 탭

- **엑셀로 내보내기** — `딴짓차단기_백업_날짜.xlsx` 로 저장됩니다
- **엑셀 파일 불러오기** — 불러올 때마다 **합치기**(지금 목록 유지 + 새 주소 추가) 또는 **덮어쓰기**를 고릅니다
- 엑셀 구성: `차단목록` · `예외목록` 시트(A열에 도메인), `설정` 시트(차단 화면 문구), `안내` 시트
- 엑셀에서 직접 고쳐서 불러와도 됩니다. `https://` 나 경로가 붙어 있어도 도메인만 읽고, 주소가 아닌 칸은 건너뛰고 알려줍니다
- 잠금을 켜두면 이 페이지도 단어 문제를 풀어야 열립니다

### 차단 화면

- 차단되면 **어떤 주소가 막혔는지** 전체 주소가 표시됩니다 (복사 버튼은 2.0.3 에서 뺐습니다)
- 어느 차단 규칙(도메인)에 걸렸는지도 함께 표시됩니다
- 문구는 **□ / "잠깐!" / "딴짓 차단기 작동 중"** 으로 고정입니다.
  팝업에서 고치는 칸은 없애고, 꼭 바꾸고 싶으면 백업 엑셀의 `설정` 시트에서 바꿉니다

> 차단 화면이 떠 있는 탭에서 **새로고침을 하면 계속 차단 화면이 나옵니다.** 그 탭의 주소는 이미 확장 프로그램 페이지로 바뀌어 있기 때문입니다. 주소창에 주소를 다시 입력해서 접속하세요.

## 동작 방식

`declarativeNetRequest` 동적 규칙으로 페이지 요청 단계에서 차단하므로 HTTPS 사이트도 로딩되기 전에 막히고, 차단 시 `blocked.html` 안내 페이지로 이동합니다.

예외는 **두 겹**으로 걸려 있습니다.

1. 차단 규칙(`redirect`, priority 1)의 조건에 `excludedRequestDomains` 로 예외 도메인을 넣어 **매칭 자체가 안 되게** 함
2. 예외 규칙(`allow`, priority 2)을 따로 추가 — 우선순위가 높아 차단을 이김

둘 중 하나만 동작해도 예외가 유지됩니다.

  빨간 정지 표지(🛑)가 불법 사이트 경고처럼 보인다는 의견에 따라 한글 `ㅁ` 으로 바꾸고 회색 처리.

- 옛 기본 문구를 그대로 쓰던 기기는 `initDevice()` 가 새 기본값으로 바꿔준다.
  직접 고친 문구는 건드리지 않는다

### 2.0.0
- **비밀번호 기능 삭제.** `passHash`·`salt`·해시 코드·비밀번호 찾기 화면 제거.
  대신 **잠금 = 단어 한 문제**. 5분 유지와 잠금 켜기/끄기는 그대로.
  v1.x 에서 비밀번호를 걸어 두었던 기기는 **잠금이 켜진 상태**로 넘어온다 (`initDevice()`).
- **단어를 사용자가 정한다** — 백업 엑셀에 `단어` 시트 추가. 읽기·쓰기 모두 지원하고 동기화된다.
  쓸 수 있는 줄이 4개 미만이면 불러오기를 막고, 저장된 목록이 모자라면 기본 10개로 대체한다.
- **동기화 기록**(`h0`~`h9` 링 버퍼 + `hi`/`hn`) — 그 시점의 목록 전체를 최근 10개까지.
  같은 기기의 5분 내 연속 변경은 한 칸으로 묶고, 되돌리기는 묶지 않는다.
  항목 8KB·전체 100KB 한도에 맞춰 오래된 기록부터 버리고, 한 칸에도 안 들어가면 기록을 건너뛰며 알린다.
- **되돌리기** — 기록의 한 시점으로 통째로 복원(스냅샷 복원). `revertFrom` 을 남겨 기록에 "되돌림"으로 표시.
- **기기 이름** — OS 기준 자동 이름 + 설정에서 변경. 같은 이름의 다른 기기가 있으면 뒤에 번호를 붙인다(`deviceId` 로 구분).
- 동기화 스키마 v2 (`words` 추가, `passHash`/`salt` 제거). v1 데이터도 읽어 들이고 첫 push 때 정리한다.
- `background.js` 가 `common.js` 를 importScripts 해 DEFAULTS 를 한 곳에서 관리.

- **버그 수정**: 서비스 워커 기동과 목록 변경이 동시에 일어나면 규칙 등록이 두 번 실행되어
  `Rule with id N does not have a unique ID` 오류로 **규칙 적용 전체가 실패**했다.
  그 결과 예외(allow) 규칙만 등록되지 않아 "차단은 되는데 예외가 안 먹는" 증상이 발생.
  - 규칙 적용을 직렬 큐로 처리해 동시 실행을 막음
  - 삭제 목록(`removeRuleIds`)에 새로 추가할 ID까지 포함시켜 ID 충돌을 원천 차단
  - 중복 호출의 원인이던 `onInstalled` / `onStartup` 리스너 제거 (서비스 워커 기동 시 한 번만 실행)

## 알아둘 점

- 잠금에는 비밀번호가 없습니다. 단어 문제의 정답은 확장 프로그램 파일 안에 그대로 들어 있습니다 (의도된 수준)
- 확장 프로그램 자체를 `chrome://extensions` 에서 끄거나 삭제하면 차단도 풀립니다. 완전히 막으려면 hosts 파일 방식이나 OS 계정 정책이 필요합니다
- 시크릿 모드에서 적용하려면 확장 프로그램 상세 화면에서 **시크릿 모드에서 허용** 을 켜야 합니다
- 예외로 연 사이트가 로그인 리디렉션(`nid.naver.com` 등)을 거치면 그 중간 주소도 예외 목록에 넣어야 정상 동작합니다

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 프로그램 정의 (Manifest V3) |
| `background.js` | 차단/예외 목록 → 네트워크 규칙 변환 |
| `popup.html` / `popup.js` | 차단·예외 목록 관리, 설정, 잠금 문제 |
| `blocked.html` / `blocked.js` | 차단 시 표시되는 안내 페이지 |
| `options.html` / `options.js` | 동기화 기록 · 되돌리기 · 백업 · 불러오기 |
| `common.js` | 공용 코드 (기본값, 도메인 정리, 잠금 상태, 기록 읽기) |
| `xlsx.js` | 엑셀 파일 읽기·쓰기 (외부 라이브러리 없음) |
| `sync.js` | 크롬 동기화 (백그라운드) |
| `words.js` | 잠금 문제 단어(기본 10개) · 문제 생성 |
| `icons/` | 확장 프로그램 아이콘 |
